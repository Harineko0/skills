# 利用者本人の文体（陶山 / ゆにねこ）

## 1. 媒体でガイドを選ぶ

- **メール・公式/社外の文書**: [`email.md`](email.md) を読む。
- **Google Chat・チームチャット（日本語・英語）**: [`google-chat.md`](google-chat.md) を読む。

## 2. 全媒体で共通する原則

- **結論と要件を先に書く**: 時候や長い前置きは省き、お礼・お詫び（必要なら 1 行）→ 結論・要件 → 理由や手順の順で書く。
- **名乗りの使い分け**: 企業・人事・契約・公式連絡は `陶山`（団体活動は必要に応じて `GDG Greater Kwansai`）、社内技術チャットやコミュニティでは `ゆにねこ` / `Yunineko`。
- **一文を短く保つ**: 1 行 1〜2 節に収め、情報が多いときは段落または行を分ける。
- **事実と根拠をセットにする**: 依頼や決定には「なぜそうするか」「具体的な URL / ID / 手順 / 選択肢」を短く添える。
- **不確実さを正直に示す**: 未確定なことは断定せず、`〜かもです` / `〜と思われます` / `〜のようです`（英語は `I suppose` / `It seems` / `maybe`）で留保する。
- **補助動詞・形式名詞はひらがなで書く**: `いただく`、`ください`、`できる`、`ありがとう`、`ございます`、`ため`、`こと`。
- **過度に硬い定型や AI 調の装飾を避ける**: `所存です`、`何卒`、`謹んで`、まとめ段落、不要な比喩や強調は使わない。

## 3. 推敲の使い分け

- メールや長文のお知らせ・提案は `/yomiyasu` を併用して主述と論理を整える。
- チャットの通常返信では、文末の句点省略・主語の省略・半角スペース・絵文字（`🙇` `🫡` `🙏`）など [`google-chat.md`](google-chat.md) の口調をそのまま保つ。
